# --- Testing (Phase 2 additions) ---
# The `lua` extra (-> lupa, Lua-in-Python bindings) is not optional here: G2's
# rate limiter goes through flask-limiter -> the `limits` library, which
# implements its moving/fixed-window hit tracking as Lua scripts (EVAL/
# EVALSHA) for atomicity. Bare `fakeredis` doesn't register those commands at
# all, so every rate-limit check against it fails closed with "unknown
# command 'evalsha'" -- indistinguishable from a real outage, since the app
# correctly treats an unreachable-looking Redis as fail-closed (G2). Found by
# a real hang/false-503 on a fresh install (tests/api/test_rate_limit_redis.py
# ::TestMidSessionRedisFailure), not by reading fakeredis's changelog.
