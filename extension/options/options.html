Off by default (recommended). When off, only the page's scheme://host is sent to the API — never the path, query string, or fragment, which can contain sensitive data (session tokens, search terms, email addresses in a login form's query string, etc).

Active Protection Mode (opt-in)

When enabled, ARGUS checks every site you navigate to (hostname only, same privacy floor as the popup's passive check) before the page loads, and warns you if it's flagged. This requires the browser's webNavigation permission plus access to all http/https sites, which Chrome will prompt you to grant. Manifest V3 doesn't allow extensions to truly block a navigation, so on a fast-loading page the original content may flash briefly before the warning replaces it — a browser platform limitation, not a bug.
